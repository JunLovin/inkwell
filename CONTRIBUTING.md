# Contributing

Thanks for your interest in contributing to Inkwell.

The full contribution guide — local setup, commands, code style, testing, PR workflow — lives in [**docs/CONTRIBUTING.md**](./docs/CONTRIBUTING.md).

Before opening a PR, please also read:

- [Code of Conduct](./CODE_OF_CONDUCT.md)
- [Architecture overview](./docs/ARCHITECTURE.md)
- [Convex backend guide](./docs/CONVEX.md) — if you're touching backend code

For anything larger than a small bug fix, please open an issue or discussion first so we can align on approach before you write code.
