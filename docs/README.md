Welcome. This folder holds everything you need to understand, run, and contribute to Inkwell.

- [**CONVEX.md**](./CONVEX.md) — The backend guide: schema, function catalog, auth, AI action, cron behavior, and env vars.

## Sources of truth

Docs describe how the project *should* work; when they disagree with the code, **the code wins**. Three in-repo files sit closest to reality and are worth knowing:

- `CLAUDE.md` — the canonical internal guide for AI agents working on this repo. Deep style rules and directory conventions live here.
- `AGENTS.md` — short reminder that this Next.js version has breaking changes; agents should read the actual Next.js docs in `node_modules/next/dist/docs/`.
- `convex/_generated/ai/guidelines.md` — Convex's own rules, regenerated by the CLI. Overrides anything you learned about Convex elsewhere.

If you find drift between any of these docs and the code, PRs to fix it are welcome — see [CONTRIBUTING.md](./CONTRIBUTING.md).
