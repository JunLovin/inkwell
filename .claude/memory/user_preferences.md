description: Hard rules on what never to do in this project
type: feedback
---

Never add comments to code — no inline, block, JSDoc, or any `//` comments.

**Why:** Explicit user instruction; clean, self-documenting code is the standard here.

**How to apply:** Strip all comments from any code written or edited in this project. If asked to explain code, do it in chat, not in comments.

---

Never commit, push, open PRs, or create GitHub issues.

**Why:** Explicit user instruction; all VCS actions are the user's responsibility.

**How to apply:** Skip any git commit/push/PR/issue steps even when it would "complete" a task.
